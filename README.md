# DavAktiv_AI — boshlang'ich struktura

Xodimlar davomatini yurituvchi tizimning qatlamlarga ajratilgan tuzilmasi.

- `src/models` — ma'lumot obyektlari (Employee, AttendanceLog)
- `src/repositories` — ma'lumotni saqlash
- `src/services` — biznes qoidalar
- `src/controllers` — tashqi so'rovlarni qabul qilish
- `tests` — testlar
- `config` — sozlamalar
